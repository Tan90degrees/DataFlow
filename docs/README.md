# DataFlow documentation

English | [简体中文](zh-CN/README.md)

DataFlow is a small Python component for declarative data pipelines in one existing Ray cluster.
The package has no server or database to deploy.

- [Getting started](getting-started.md): install, prepare input, connect and run.
- [Execution architecture](single-cluster.md): streaming, branches, control dependencies and limits.
- [SDK and JSON reference](sdk.md): authoring, resources, configuration and return values.
- [Deployment and operations](operations.md): shared workers, filesystems, memory, retries and diagnostics.
- [Development and verification](development.md): tests, packaging, containers and CI.
- [Migration to 0.2](migration.md): removed interfaces and replacement commands.
- [Roadmap](roadmap.md): current capabilities and remaining acceptance work.
- [Performance experiments](performance.md): reproducible concurrent DAG benchmarks and measurement limits.
