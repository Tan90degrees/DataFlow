# 路线图与验收边界

[English](../roadmap.md) | 简体中文

当前实现包括可序列化 DAG/SDK、执行前校验、每 worker 资源提示、连接已有唯一 Ray 集群、
线性惰性执行、对象存储分支复用、控制依赖、同步结果与异常，以及轻量 JSON CLI。
输入输出目前为 Parquet，源码和文档只维护这条执行路径。

下一阶段按真实工作负载验收：集群稳定性、持续吞吐和尾延迟、CPU/IO/模型混合流水线、
对象存储及 spill 压力、worker 丢失、driver 故障、重提和宿主管理的幂等。
单元测试通过不代表完成生产验收。

可能的功能方向包括更多输入输出、明确的 fan-in 语义、高效流式分支和更好的宿主进度/取消接入。
当前每个 driver 内的独立 sink 仍串行执行。这些均未实现，应由具体业务需求决定优先级，
不构成功能承诺或性能结论。

多集群编排、独立数据库/控制面、权限审计服务和基于存储的中间制品协议不在当前组件范围内。
