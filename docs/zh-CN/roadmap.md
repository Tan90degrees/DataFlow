# 路线图与验收边界

[English](../roadmap.md) | 简体中文

已实现可序列化 SDK/JSON DAG、数据/控制依赖、有界节点与 sink 并发、显式缓存屏障、同 schema union、
按键 shuffle join，以及具备有界 DAG 准入和完成顺序结果迭代的常驻 runner。
全部在一个已有 Ray 集群中执行，不使用基于存储的中间传递协议。

单元测试覆盖并发重叠/上限、队列背压、取消、失败等待清理、输入窗口、规格快照和汇合端口；
真实 Ray 与可复现合成基准单独验证实际执行。基准结论依赖工作负载，测试通过不代表生产验收或全局最优。

下一阶段：真实 OCR/页/BOX 负载、内存压力下持续吞吐和延迟、对象存储及 spill 峰值测量、worker/driver
故障验收、更智能的共享策略、跨 DAG 模型 actor 复用，以及可选宿主进度/取消接入。
默认分支可能重算，join 可能物化和 shuffle；尚未实现无复制流式广播、自动内存感知准入或集群全局公平调度。

集群生命周期、请求持久历史、重提和业务幂等由宿主负责。
多集群编排、独立权限/审计/数据库/控制面及 S3 中间制品协议仍不在组件范围内。
